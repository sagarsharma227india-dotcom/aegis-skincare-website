# AEGIS MEN — Evidence-Informed Clinical Grooming Architecture

Modern, high-performance skincare formulated specifically for male dermal biology (stratum corneum thickness, testosterone-driven sebaceous secretion rates, and razor microtrauma).

## Tech Stack
- **React 18** with **TypeScript**
- **Vite** bundler
- **Tailwind CSS**
- **Motion** (`motion/react`) for smooth physical layout animations
- **Lucide React** icons

## Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Run Development Server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

### 3. Production Build
```bash
npm run build
npm start
```

## Features
- **The Starter System Hero Showcase**: 3-piece clinical protocol (WASH, HYDRA, SHIELD SPF 50) with interactive bottle spotlight, AM/PM routine switcher, and clinical validation metrics.
- **Formulary / Shop**: Complete filtering by clinical category, skin concern, step, and targeted actives.
- **Diagnostic Routine Finder**: 2-minute diagnostic questionnaire generating custom clinical regimens based on dermal type and shaving frequency.
- **The AEGIS Journal**: Peer-grounded, comprehensive clinical treatises on stratum corneum architecture, photobiology, follicular lipid chemistry, and evidence-based routines (6–8 min reads).
- **Product Dossiers**: Deep-dive modals with full INCI ingredient breakdowns, clinical trials data, pH specifications, and application protocols.
- **Cart & Bag Architecture**: Interactive drawer with threshold-based perks, tier progress, and checkout simulation.
