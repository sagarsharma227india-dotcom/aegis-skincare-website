# AEGIS MEN — AI-Powered Skincare Platform

## ✨ Key Features

- 🤖 AI-powered skincare assistant
- 🧠 Interactive skin diagnostic quiz
- 🛍️ Product discovery and e-commerce experience
- 🔬 Ingredient and skincare education
- ❤️ Wishlist and shopping cart interactions
- 📱 Responsive design for desktop and mobile
- 🎨 Premium **Science × Simplicity** design system

## 🛠️ Tech Stack

- React
- TypeScript
- Vite
- Tailwind CSS
- Lucide React
- HTML5 Canvas
- Vercel

## 🎯 Project Focus

AEGIS MEN explores how **AI, personalization, UI/UX, and e-commerce** can work together to simplify men's skincare.

**User journey:**

`Understand Skin → Identify Concern → Get Guidance → Discover Products → Build a Routine`

## 🎨 Design

The interface follows a **Laboratory-to-Editorial** aesthetic with:

- Playfair Display + Inter typography
- Warm off-white surfaces
- Deep charcoal text
- Soft sage accents
- Minimal layouts
- Subtle micro-interactions

## ⚠️ Disclaimer

AEGIS MEN is an **independent website concept** created for development, design, and portfolio purposes. It does not represent an officially operating commercial skincare company.
